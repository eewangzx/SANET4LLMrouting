# 问题、实现与论文证据边界

## 研究问题

在算力与链路状态快速变化、遥测带宽有限且信息延迟的协同边缘服务系统中，如何从本地历史观测得到低比特、含预测信息的表征，使控制器在原 ICC 部署与执行约束下，降低任务 deadline 违约和运行成本？

这里的 routing 是服务 DAG 的协同执行与节点选择。当前代码没有不同 LLM 回答质量的候选模型选择；称为完整的质量感知 LLM model routing 会超出实现。

## 保留的 ICC 数学结构

节点 n 的核心实例数为静态决策 x^cr，轻服务实例数为 x^lt(t)，实例并行度为 y(t)，DAG 阶段路由为 a(t)。每个节点的资源向量满足

\[
\sum_{s\in\mathcal S_{cr}}r_s x^{cr}_{sn}
+\sum_{s\in\mathcal S_{lt}}r_s x^{lt}_{sn}(t)\preceq R_n.
\]

整数性、运行中实例不可错误删除、已有并发任务不可挤出、单实例最大并行度等由原执行器检查。多个副本增加可用服务容量并消耗资源；单实例并行准入不把其总处理能力简单乘以并行度。

任务 j 的 SLA 沿用原完整 DAG 的端到端 deadline：

\[
T_j^{E2E}\le D_{\operatorname{type}(j)}.
\]

处理、通信、等待与前驱依赖共同决定 T。按时率分母是全部到达请求；未完成请求也在分母。没有新增回答质量阈值。成本包括原核心与轻服务的部署、维护与并行成本。核心部署在同负载的所有方法间完全一致。

## 扩展：受限观测与预测压缩

每个节点的历史窗口 X_n(t) 为 8×16 float32，采样间隔 5ms。16 个特征包括九种轻服务的速率乘子、至多五个有序邻接链路乘子和两个历史汇总量。拓扑缺少的链路位置以 1 补齐。原始窗口并非无需观测的免费统计量。

\[
z_n(t)=g_\theta(X_n(t)),\qquad
\widehat S_n(t:t+H)=d_\phi(z_n(t)).
\]

8 个历史时刻一起编码为**一个 z**，不上传 8 份 latent。预测头输出当前到未来 300ms 的序列；未来标签只用于离线/训练辅助损失。部署时只接收实际到达报文中的 z、时间戳及筛选掩码。

| 表征 | 载荷 | 含 16B 公共头部的报文 | 目的 |
|---|---:|---:|---|
| raw | 128 float32 = 512B | 528B | 完整历史、学习预测头 |
| stats16 | 16 float32 = 64B | 80B | 当前特征与历史摘要、学习预测头 |
| stats4 | 4 float32 = 16B | 32B | 均值与斜率、分析外推；同字节强对照 |
| dense4 | 4 float32 = 16B | 32B | 单个预测 latent |
| importance | 3 float32 + 1 个掩码字 = 16B | 32B | 8 个候选 latent 中选择 top-3 |
| ae4 | 4 float32 = 16B | 32B | 重建预训练，冻结编码器后学习预测头 |

当前 importance filter 是硬 top-k 前向与直通梯度近似，附加选择预算正则；**不是已实现的信息瓶颈互信息损失，也不宣称逐层复刻 SANet**。掩码实际计入字节。目前三种紧凑学习表征与 stats4 同字节，需要证明在这个强对照下仍有价值。

64kbit/s 是所有节点共享的遥测信道，FIFO 串行传输；同节点未发送的旧报文可以被新报文替换。控制端按生成时间计算 AoI 并对预测序列进行时间对齐，尚无上报的节点使用名义先验。报文头、载荷、部分已发送字节均计费。

当前上报周期和表示长度是实验配置，PPO 不选择报文发送时刻。因此当前 PPO 的通信罚项在同编码器/同周期对比中近似常数，不能宣称已经学会自适应上报。窄带收益首先应通过报文大小、AoI 与调度结果证明。

## 分层学习控制

当前 PPO 从收到的 z、AoI、可见部署/任务账本选择 (eta 倍率, 并行度上限)，共九种模式。原 ICC 控制器随后解出可行的实例数、并行度和阶段路由。它保留虚拟队列与 effective-capacity 近似，使用预测服务可用度更新时延估计。

奖励按每控制间隔的累计计数差定义：

\[
r_t=-\Delta C_t/100-2\Delta N_{late,t}
-0.01\Delta B_t/32.
\]

这是原运行成本、完整任务 deadline 失败和实际遥测字节的加权目标。原资源约束由执行器严格执行；奖励惩罚**不等于硬 SLA 概率保证**。背景动态破坏了简单独立同分布假设，原 EC 理论不能不加条件地直接移植。

冻结编码器与联合训练分别运行；联合版本含 PPO 和预测辅助损失。critic 不向编码器反传。importance 的离散筛选与下层求解器导致整体属于实用组合算法，目前不主张全局最优、最低维充分统计量或严格联合策略梯度收敛定理。

数值优化对整个奖励固定乘 0.001，使典型 critic 目标落在个位量级；物理奖励报告、奖励各项相对权重和验证选模目标不变。gamma=0.995/ms，GAE lambda=0.995/ms，按实际间隔指数折扣。旧未缩放版本仅作为训练失效诊断保留；value loss 的量级降低本身不算收益。

## 因果性与物理边界

- 真实链路/算力只驱动物理执行；控制器只能看已到达报文的预测。
- 真实在途数据到达时间、真实剩余处理工作量不传给控制器。
- 控制账本、完成/占用 ACK 视为各方法共同的独立机制；目前计费的是资源/链路遥测，不是全部控制流量。
- 保留原独立传输模型，沿名义路径积分时变速率；没有新增共享数据链路队列。
- 物理、部署控制与 EC 准入窗口主实验均为 1ms。核心处理时长保持原设置，新增算力动态作用于轻服务。
- 静态背景时与原始执行语义回归一致。动态背景不是作者原始测量轨迹。

## 论文主张需要的证据

1. **通信受限的预测状态建模**：给出 bit、AoI、链路变化时间尺度和决策时延的明确关系。仅把 AE 与 PPO 拼接不足以支持强贡献。
2. **面向决策的表征**：在 stats4 同字节、stats16 强统计、普通 AE、无 filter、完整历史等对照下，降低实际 DAG 违约/成本。预测 MSE 更小不自动意味着路由更好。
3. **长时控制价值**：比较原 ICC 控制器、在验证集挑选的最佳固定控制模式、冻结编码器 PPO 与联合 PPO。不能只拿未经优化的启发式或随机策略比较。

目前第一个建模和工程闭环已实现；第二、第三项仍需要正向实验证据。第一轮两个测试种子上的 importance 按时率低于统计与完整历史，不支持收益宣称。

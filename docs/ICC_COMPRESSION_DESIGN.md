# 低于统计量维度的主实验

本轮检验：将每节点报文从 16 维统计量的 80 B 降到 4 维表征的 32 B 后，能否保持或提高 SLA 达标率。4 维是主设置，8 维是维度消融；16 维学习模型仅为辅助对照。

## 固定设置

- 输入为每节点 8 × 16 = 128 维状态历史，采样间隔 5 ms。
- 每个值按 float32 传输，报头固定 16 B。因此 4/8/16 维报文分别为 32/48/80 B。
- 所有方法采用相同周期上报，扫描 20/50/100/200 ms；三个节点共享 64 kbit/s 上报链路。
- ICC 公开参数重建场景、0.05 倍到达强度、动态链路和算力、逐时隙 Gamma 速率均沿用上一轮。没有为本轮另加共同隐变量或跨资源时滞耦合。
- 任务截止时间 50–100 ms，质量阈值 0.8。指标为质量与截止时间均达标的数量 / 全部到达请求数；拒绝和运行结束时未完成的请求不从分母删除。
- 测试种子 241、242、243，每次到达阶段 2 秒，另留 150 ms 排空。所有方法和周期逐种子检查外生轨迹哈希一致。

## 真正的低维瓶颈

编码器最后一层直接输出 4 或 8 个数；解码器和预测器的输入也分别只有 4 或 8 维。因此本轮不是将先前训练好的 16 维模型在测试时截短。

为保持路由 actor 的接口与隐藏层结构一致，输入接口在本地补零至 16 个位置。补零位置没有信息、不进入报文；测试验证训练窗口路径与实际接收报文路径输出相同。

各维度独立从头进行 AE 预训练和预测器训练，所有阶段固定相应维度。在每个维度内，冻结 AE 基线与联合编码方法从完全相同的预训练权重开始：

- `ae4` / `ae8`：冻结编码器与解码器，训练预测器和 PPO。
- `semantic4` / `semantic8`：编码器、解码器、预测器与策略接受联合训练。

预训练各 20 个重建/预测 epoch；策略热启动 20 个 epoch；PPO 10 次更新，每次两条完整轨迹。训练阶段每条轨迹到达阶段为 1 秒；四个上报周期各出现 5 次。所有模型使用训练种子 7。

16 维统计量、16 维 AE 和16 维联合模型复用 `runs/icc_frequency_matched/checkpoint.pt` 的同训练配置权重，并在本轮新测试种子上重新评估。程序核对训练配置、训练种子、上报周期、预训练和 PPO 预算匹配。它们同样使用预测和 PPO。

## 如何判断

主比较为 `semantic4` 对 `stats16`，并报告每条轨迹的 SLA 差值和实际发送字节减少比例。`semantic8` 是维度消融，低维 AE 则区分普通压缩与任务联合训练的效果。

不能直接把每包减少 60% 当成任何负载下的实际发送速率都减少 60%：20 ms 时统计量产生速率为 96 kbit/s，超过链路容量；4 维报文产生速率为 38.4 kbit/s。50 ms 及更长周期下，两者产生速率均低于容量。

本轮仍只有一个训练种子、三个测试轨迹，不能据此宣称统计显著优越或严格非劣。没有假定“4 维必然足够”。统计量尚未量化或删减，实验结论限定于当前 float32 基线，不等于证明最低比特表示。

ICC 数据是公开参数重建，备选模型为合成代理配置；无真实 LLM profiling。编码延迟统一配置为 0.2 ms，路由/解码 CPU 时间未计入物理时钟。当前策略为前馈 PPO，没有新增队列记忆。

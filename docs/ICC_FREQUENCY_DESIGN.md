# 降低上报频率：假设与对照设计

研究假设是：当上报间隔变长、信息变旧时，可靠的未来资源预测和考虑后续队列影响的路由策略可能更有价值。这不意味着只要降低频率，联合编码器就一定胜过其他方法。

## 先明确比较对象

上一轮 `window_stats_ppo` 与 `ae_ppo` 都有预测器，并使用与联合编码器相同的 PPO 长期折扣回报。因此预测和长期优化不是原表格里联合编码器方法独占的能力。

本轮统一采用周期上报，扫描 20、50、100、200 ms。每节点每次上报 16 个 float32，含报头共 80 B，三个节点共享 64 kbit/s 上报链路。所有方法用相同采样时刻、相同包长和相同上报周期；不使用事件触发，也不改变 latent 维数。

| 周期 | 每节点名义上报频率 | 三节点合计产生速率 |
|---|---:|---:|
| 20 ms | 50 Hz | 96 kbit/s |
| 50 ms | 20 Hz | 38.4 kbit/s |
| 100 ms | 10 Hz | 19.2 kbit/s |
| 200 ms | 5 Hz | 9.6 kbit/s |

20 ms 的产生速率超过链路容量，待发送报文会排队或被新报文替换。降频到 50 ms 可以先减轻拥塞，未必单调增加信息年龄。因此同时记录实际发送速率、信息年龄、替换数和 SLA 达标率。

沿用 ICC 公开参数重建场景和代理模型，负载乘数为 0.05；每条测试轨迹到达阶段为 2 秒，排空阶段 150 ms。截止时间仍是 ICC 的 50–100 ms。新增资源可用率周期为 100–220 ms，叠加噪声；Gamma 速率每 5 ms 独立更新，其中不可预测的部分无法靠延长预测范围消除。

## 两个阶段

1. 固定旧权重，只改变各方法的上报周期。旧模型在高频事件上报下训练，预测跨度 100 ms；此阶段衡量原模型的频率敏感性，不作为低频训练后算法能力的最终结论。
2. 重新在 20/50/100/200 ms 周期上报下训练，预测跨度扩展至 300 ms，训练到达阶段为 1 秒。四种学习策略各用同样的 20 个预训练 epoch、10 次 PPO 更新、每次两条轨迹及固定 16 维报文。PPO 的 20 条训练轨迹轮流使用四个周期，每种周期 5 条。

四种学习策略为：统计量 + 预测 + PPO，冻结 AE + 预测 + PPO，联合编码 + 预测 + PPO，以及独立训练的“联合编码 + PPO、无显式预测”消融。最后一种将未来轨迹输入换成当前解码资源的保持值，并移除预测辅助损失，热启动也使用无预测启发式。其 latent/策略仍可隐式学到趋势；不是完全禁止任何未来推断。

另使用同一个联合编码器做预测启发式与反应式启发式对照，直接检查显式未来轨迹是否帮助同一个调度规则。最新状态 + 启发式提供简单的等包长参考。

测试种子 231、232、233 独立于训练与验证，所有方法及上报周期使用同一组外生轨迹并检查哈希。每阶段只有一个训练种子。两个阶段的预测跨度和预生成数组长度不同，不直接把跨阶段数值之差解释为训练增益。

## 如何解释结果

- 联合编码与统计量/冻结 AE 的比较检验表示学习价值，不单独检验预测或长期 RL 的价值。
- 同编码器的预测/反应式启发式，及独立训练的无显式预测消融，用来检查显式预测的价值。
- PPO 与启发式的差异涉及模型容量、训练和目标等多个因素；本轮没有独立识别长期回报的贡献，不能把所有差值归因于 long-term optimization。
- 现有 PPO 是前馈 actor，并未显式维护两次上报之间“自己已经分配但尚未收到反馈”的负载记录。长期折扣奖励不等同于在线状态记忆。更低频时，这可能成为瓶颈。
- 预测以旧报告的采样时刻为起点。300 ms 虽扩大了范围，但在最坏的上报年龄、传输延迟和完整任务截止时间之和超过该范围时，末尾仍采用常值延伸；不能声称始终有完整可靠预测。

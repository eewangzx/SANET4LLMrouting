# 降低上报频率后的结果

本轮完成 72 次旧模型频率扫描、四种策略的匹配条件训练、84 次匹配评估，共 156 次评估。61 个测试通过。结果部分支持“低频上报时预测更有价值”的假设；还没有证明联合编码框架稳定优于所有强基线，也没有单独识别长期 RL 的收益。

## 相同信息预算下的匹配实验

统一使用周期上报、每节点每报文 16 个 float32 加报头共 80 B、共享上报容量 64 kbit/s。每个周期及种子内，所有方法的外生轨迹、生成/发送字节数和决策时信息年龄完全相同，检查通过。本组只比较固定 16 维表示，不包含完整 528 B 窗口或自适应报文长度。

使用 ICC 公开参数重建场景的 0.05 倍到达强度，代理模型质量/运行时间设定仍没有真实 LLM profiling 支撑。测试种子 231、232、233，每次到达阶段 2 秒，排空 150 ms。指标为质量 ≥ 0.8 且在任务截止时间内完成的请求数 / 全部到达数。

重新训练覆盖 20/50/100/200 ms 四个上报周期，预测跨度从旧模型的 100 ms 扩展到 300 ms。四种学习策略分别以同一个训练种子、相同初始 AE 权重（统计量不需要 AE）、同一 PPO 更新预算训练。训练阶段为每轨迹 1 秒到达；每种周期各用 5 条 PPO 轨迹，共 20 条。测试没有参与参数选择。

| 上报周期 | 统计量 + 预测 + PPO | 冻结 AE + 预测 + PPO | 联合编码 + 预测 + PPO | 联合编码 + PPO，无显式预测 |
|---|---:|---:|---:|---:|
| 20 ms | **32.77%** | 30.15% | 29.00% | 25.13% |
| 50 ms | **32.04%** | 31.60% | 29.86% | 25.58% |
| 100 ms | 28.01% | 27.07% | **28.42%** | 23.00% |
| 200 ms | 21.91% | 23.51% | **23.72%** | 18.97% |

完整联合方法相对无显式预测版本的配对平均提升依次为 **3.87、4.28、5.42、4.74 个百分点**。四个周期、三个种子构成的 12 组配对均为正差值。这是本轮较明确的预测消融证据，但提升没有随着周期继续延长而单调扩大。

相对强基线的结论更弱：100 ms 下，联合方法对统计量和 AE 分别高 0.42、1.35 个百分点；200 ms 下分别高 1.81、0.21 个百分点。100 ms 对统计量只在 1/3 条轨迹领先，200 ms 对 AE 也只在 1/3 条轨迹领先。因此不能把均值上的交叉解释成稳定或统计显著的算法优势。

## 上报与信息年龄

同一周期下不同方法具有相同的报文时序和长度，因此收益不来自某方法偷偷更频繁地上报。信息年龄按每个请求做决策时看到的报告采样时间计算，是请求加权均值；不同随机到达轨迹的均值可以略有不同。

| 上报周期 | 三节点合计名义产生速率 | 平均决策时信息年龄 |
|---|---:|---:|
| 20 ms | 96 kbit/s | 32.40 ms |
| 50 ms | 38.4 kbit/s | 47.17 ms |
| 100 ms | 19.2 kbit/s | 71.92 ms |
| 200 ms | 9.6 kbit/s | 121.43 ms |

20 ms 时产生速率超过 64 kbit/s，未发送报文会被新报告替换。降到 50 ms 后排队拥塞减少，但采样间隔变长；本轮净效果仍是信息年龄上升。实际发送速率包含初始报告和有限实验时长边界，见 CSV，而非强行等于表中名义值。

## 固定旧权重的检查

旧模型使用高频事件上报训练，预测跨度只有 100 ms。统一改为周期上报、保持旧权重后：

| 方法 | 20 ms | 50 ms | 100 ms | 200 ms |
|---|---:|---:|---:|---:|
| 统计量 + 预测 + PPO | 30.75% | 30.35% | 28.50% | 22.19% |
| 冻结 AE + 预测 + PPO | 31.43% | 30.41% | 25.70% | 18.02% |
| 联合编码 + 预测 + PPO | 25.26% | 23.95% | 23.03% | 19.32% |

仅降低测试频率，没有让旧联合模型全面超过强基线。这一阶段用于诊断频率敏感性。重新训练阶段还改变了预测跨度、训练时长及预生成数组长度，不能直接把两个阶段数值相减并全部归因于重新训练。

## 预测与长期优化的解释边界

- **统计量和 AE 基线也有预测及 PPO 长期回报。** 它们不是纯反应式或短视基线，因此不能把 proposed 与它们的差距都归因于预测/长期 RL。
- 无显式预测的学习消融是独立训练的策略：用当前解码资源的保持值替代未来轨迹、去掉预测辅助损失、用无预测启发式热启动。latent 和策略仍可能隐式学到时间趋势。
- 使用同一个联合编码器和启发式，只切换预测开关，得到的提升分别为 -0.58、+2.58、+1.19、+1.88 个百分点。这一对照也显示预测并非在所有频率下都有效。
- 固定验证历史上，联合模型的 100–200 ms 预测 MSE 为 0.0615，真实当前值保持基线为 0.0854；200–300 ms 分别为 0.0651 与 0.0994。但 AE/统计量预测 MSE 约 0.054，更低。不能将当前框架的作用解释为“预测器总是最准”。验证历史来自瞬时状态启发式，具体分布和目标记录在 `forecast_diagnostics.json`。
- 当前预测器只预测算力和链路可用率，不预测每时隙独立 Gamma 波动，也不预测由未来调度动作驱动的队列积压。超过预测跨度时采用末值延伸。
- 当前 actor 是前馈网络；它没有显式记忆两次上报之间已经分配、但还没有反馈的任务。长期折扣奖励不自动提供这种在线状态记忆。
- 本轮没有短视 RL 的独立训练对照；不能单独声称已经验证 long-term optimization 的贡献。一个训练种子、三个测试轨迹仅适合原型判断。

下一项实现重点应是：用已知路由动作更新待处理工作量估计，在新报告到达时校正；把这个可因果获得的状态或动作历史接入有记忆的策略，再检验长期调度收益。当前结果已经说明低频实验值得保留，但还不足以写成全面胜出的算法贡献。

## 交付内容

- `edge_msd/icc_routing/frequency_experiment.py`：频率扫描、匹配训练、预测消融及统计。
- `edge_msd/icc_routing/learning.py`：训练周期配置、显式预测开关；旧实验默认行为保留。
- `runs/icc_frequency_frozen/`：72 次旧权重评估。
- `runs/icc_frequency_matched/`：四种策略权重、训练记录、预测诊断。
- `runs/icc_frequency_matched_eval/`：84 次合并评估、逐轨迹 CSV、配对差值、图表。
- `runs/icc_frequency_matched_seed231/` 等：每个测试种子的原始输出。
- `runs/ICC_FREQUENCY_REPRODUCE.md`：训练和检查点复跑命令。
